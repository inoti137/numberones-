# Numberone | نامبر وان

نسخه آماده انتشار برای GitHub Pages.

## انتشار
1. همه فایل‌های این پوشه را داخل repository `inoti137/numberones-` قرار دهید.
2. در GitHub بروید به Settings → Pages.
3. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
4. Branch را روی `main` و Folder را روی `/ (root)` بگذارید و Save کنید.
5. آدرس سایت معمولاً خواهد بود:
   https://inoti137.github.io/numberones-/

## پنل مدیریت
بعد از انتشار:
https://inoti137.github.io/numberones-/admin.html
